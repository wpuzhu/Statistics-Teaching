# Statistics Teaching

Interactive teaching pages for a one-week module on the foundations of hypothesis testing, taught through the one-proportion z-test.

- `foundations.html`: binomial model, CLT, and the normal approximation (pre-work and Lecture 1)
- `explorer.html`: one-proportion z-test explorer with predict–move–explain activities (Lecture 2, lab, homework); `explorer.html#errors` opens the errors-and-power view

Live site: https://wpuzhu.github.io/Statistics-Teaching/

Author: Puzhu (Chris) Wang. All examples use invented teaching data.
